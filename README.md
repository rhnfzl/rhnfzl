I build machine learning and AI systems, and the best part is seeing them hold up in real use. Most of the work involves messy, multilingual text: language models, embeddings, retrieval, and lately the agents and tooling around them.

Based in the Netherlands, and always up for a conversation about NLP, retrieval, LLM systems, agents, evaluation and inference. Say hi at [hey@rhnfzl.com](mailto:hey@rhnfzl.com).

Recent work includes an AI assistant with a public MCP server, an embedding model, Dutch BERT and RoBERTa models adapted to a specific domain, an LLM document parser that replaced the commercial ones we tested, and a re-ranking step that made a multilingual classifier a lot more accurate.

I use coding agents every day: Claude Code, Codex, Cursor and Pi, and review what they write. An LLM is not the default. A small BERT-style model, often distilled from a bigger one, is faster and better at one narrow job. Deterministic business logic, like permissions, stays in code. Before comparing models, the bar for good enough gets set first, then tested against what runs today.

Some problems stay in my head long after the workday, and those become side projects. Most come from my own life, like making use of my Reddit saves, podcasts and workout logs, or tools that help coding agents do better work and show what they cost. Others start with someone else's problem, like a vote guide for the Dutch municipal elections. And lately, for the fun of it, some Rust.

Automation is a habit. Anything done twice gets a script the third time, at work and at home alike.

Outside of that: chai, podcasts at a speed that worries people, and the runs, lifts and boulders that keep me sane, plus some photography.
